山地果园监测平台 · 交付包使用说明
=====================================================================

一、最快看到成品（不用装任何软件）
---------------------------------------------------------------------
1. 双击本目录下的「①双击启动演示.cmd」
2. 会弹出一个命令行窗口，并自动打开浏览器到  http://localhost:8080/
3. 演示账号：
        admin  / admin123     操作员，可下发灌溉指令
        viewer / viewer123    访客，只读（控制按钮点不动）
4. 关闭：在那个窗口里按 Ctrl+C，再关掉窗口即可

   ★ 这个启动器只用 Windows 自带的 PowerShell / .NET，不需要 Node.js、不需要联网。

二、为什么不能直接双击 dist\index.html
---------------------------------------------------------------------
   构建产物用的是 ES module，浏览器对 file:// 协议下的模块加载有 CORS 限制，
   直接双击会白屏。必须通过 http 访问 —— 所以要用上面那个启动器。

三、想改代码（需要 Node.js 18 或更高版本）
---------------------------------------------------------------------
   工程在 orchard-web\ 目录里，已经带上 node_modules，正常情况下无需重新联网安装。

        cd orchard-web
        npm run dev      # 开发模式，改完自动刷新，地址 http://127.0.0.1:5173
        npm run build    # 改完重新构建，产物在 orchard-web\dist\
        npm run serve    # 用项目自带的 Node 静态服务器（端口 8080，需先 build）

   改完代码后重新 build 一次，再双击「①双击启动演示.cmd」就能看到最新效果。

   主要文件在哪：
        src\styles\theme.css       设计 token（色板 / 字体 / 圆角 / 间距 / 响应式）—— 换肤改这里
        src\utils\chart.js         图表主题与公共 option 片段
        src\utils\echarts.js       ECharts 按需引入
        src\views\                 五个页面
        src\components\            KPI 卡 / 点位卡 / 图表封装 / 坡面剖面图
        src\store\monitor.js       唯一取数入口（将来接真实后端只改这里）
        src\mock\                  演示数据（devices.js 设备台账、simulator.js 模拟引擎）

四、目录结构
---------------------------------------------------------------------
   ①双击启动演示.cmd      零依赖启动器（推荐先用这个）
   serve.ps1              启动器实际执行的 PowerShell 脚本（只读不改）
   使用说明.txt           本文件
   预览截图\              成品界面截图（7 张，供快速预览）
   orchard-web\           完整工程（源码 + node_modules + 已构建的 dist）

        src\               源码
        node_modules\      依赖（已带上，离线也能改、能构建）

        HANDOFF.md         本轮视觉重构实施手册（12 章）
        DESIGN-NOTES.md    本轮重构的决策依据记录

五、常见问题
---------------------------------------------------------------------
Q: 提示端口被占用 / 打不开？
A: 换个端口启动：
        powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1 -Port 8090
   然后手动访问 http://localhost:8090/

Q: 双击 cmd 窗口一闪就没了？
A: 多半是系统禁用了脚本执行。在 PowerShell 里执行一次：
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   或右键 cmd → 以管理员身份运行。

Q: 页面白屏？
A: 必须通过 http://localhost:8080/ 访问，不要双击 index.html（原因见第二节）。

Q: 字体显示不对？
A: 字体是本地打包的（标题 Noto Serif SC、数字 IBM Plex Mono），不联网也正常；
   若在很老的浏览器上会按系统字体回退，不影响使用。

Q: 手机 / 平板也想看？
A: 项目自带的 Node 服务器会同时打印局域网地址：
        cd orchard-web && npm run serve
   本启动器只监听本机 localhost。

六、这个版本是什么
---------------------------------------------------------------------
   演示版：数据由前端模拟引擎生成，未接入真实设备与后端，界面上方的
   「演示数据」标识就是这个意思，不要当真实数据对外展示。

   三条安全联锁（水位 <20% 禁启泵、泵超时 30 分钟自动停、流量 <0.05 判
   空转堵转）目前只在前端模拟；接真实设备前必须移到服务端 —— 详见 README.md
   的「换成真实后端时要改什么」。
