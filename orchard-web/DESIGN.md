# 视觉规范 · One UI 设计语言

> 本文是界面视觉的唯一依据。**全部 token 集中在 `src/styles/oneui.css`，改那一个文件就能整体换肤。**

---

## 为什么选这套

定稿前做了三版原型对比（留档在 `preview/`）：

| 原型 | 方向 | 结论 |
|---|---|---|
| `style-C-light.html` | 浅色农业科技风 | 备选，边框感偏重、对比偏硬 |
| `style-D-glass.html` | 深色玻璃拟态 | 投影好看，但手机/纸质截图会糊，且"通用大屏"感重 |
| **`style-K-samsung.html`** | **One UI（三星）** | ✅ **定稿** —— 干净、留白足、状态表达克制，农业场景不显突兀 |

## 六条核心特征与落地方式

### 1. 大圆角
| 层级 | 半径 |
|---|---|
| 外层卡片 | `26px`（`--r-xl`） |
| 内层容器（气象格、联锁格、报警行） | `20px`（`--r-lg`） |
| 中间层（输入框、小区块） | `14px` / `10px` |
| 按钮、标签、进度条 | 全圆 `999px`（`--r-pill`） |

### 2. 分层阴影，不用描边
One UI 的容器**没有边框**，靠阴影分层。三段：
```css
--el-1: 0 1px 2px rgba(16,24,32,.04), 0 2px 8px rgba(16,24,32,.045);   /* 静止 */
--el-2: 0 2px 4px rgba(16,24,32,.045), 0 8px 22px rgba(16,24,32,.07);  /* 悬停 */
--el-3: 0 4px 10px rgba(16,24,32,.06), 0 18px 40px rgba(16,24,32,.1);  /* 浮层 */
```
关键是**两段**：贴边 1–2px 定形，大扩散出体积。只写一段会显得脏。

### 3. 留白优先
- 卡片内边距 `22px 24px`
- 栅格间距 `18px`（`--gap`）
- 页面左右留白 `30px`

### 4. 主色克制
青绿 `#0aa8a0` **只出现在四处**：选中态、状态圆点、进度条、关键链接。
其余全是白与灰。**大面积上色是"廉价感"的主要来源**，这条是整套规范里最要紧的。

配套语义色（各配一个 soft 底色）：

| 用途 | 主色 | 浅底 |
|---|---|---|
| 主色 / 正常 | `#0aa8a0` | `#e6f6f5` |
| 信息 / 液位 | `#2b7fe0` | `#e8f2fd` |
| 警告 / 注意 | `#e8961e` | `#fdf3e3` |
| 危险 / 告警 | `#e0574f` | `#fdeceb` |

### 5. 标题轻、数字重
- KPI 数字 `42px` + `letter-spacing:-0.05em` + `font-weight:700`
- 点位数字 `30px`，同一套字距
- 标题 `font-weight:700` 但字号小、字距收紧
- **对比靠字重与字号，不靠颜色** —— 这是 One UI 的排版观

### 6. 状态用点 + 细条
不用整块变色。做法：
- **状态圆点**：8px，带 4px 柔光圈（`box-shadow: 0 0 0 4px var(--accent-glow)`）
- **数值刻度**：5–6px 全圆角进度条，把 10–48% 的含水率映射成宽度
- 离线点：**去掉光圈** + 底色转灰，视觉上明显"退后"

## Element Plus 的适配

在 `oneui.css` 末尾统一覆盖，原则是**去掉默认的边框与方正感**：

| 组件 | 改动 |
|---|---|
| `.el-card` | 去边框，换 `--el-1` 阴影，圆角 26px |
| `.el-table` | 无竖线、无外框；表头浅底；行悬停用极浅色 |
| 输入框 / 选择器 | 浅底 + 全圆角胶囊 + 聚焦时青绿描边 |
| 按钮 | 胶囊形、无边框；主按钮带青绿投影 |
| 单选按钮组 | 分段胶囊，选中态青绿实心 + 投影 |
| 标签 `.el-tag` | 无边框、胶囊、柔和底色 |
| 弹窗 / 抽屉 | 26px 圆角 + `--el-3` 阴影 |

## 图表规范

集中在 `src/utils/chart.js`：

- **网格**：`#f1f4f7` 实线，极浅；不画轴线、不画刻度线
- **折线**：宽 2.2px、`smooth: 0.35`、`symbol: 'none'`、圆头
- **图例**：圆点图标（`circle`）8px，避免大色块
- **阈值线**：虚线 + 透明度 0.5 + **标签放线右端并带白色底衬**（否则会压住曲线）
- **tooltip**：白色大圆角卡 + 柔和阴影，带 `padding`
- **配色顺序**：青绿 → 蓝 → 橙 → 紫 → 青 → 红 → 绿

## 换肤指引

要改配色，只动 `src/styles/oneui.css` 开头那段 `:root`：

```css
--accent: #0aa8a0;        /* 换主色只改这里和 --accent-soft */
--accent-soft: #e6f6f5;
--r-xl: 26px;             /* 换圆角风格改这里 */
--el-1: ...;              /* 换阴影风格改这三段 */
```

`:root` 里的 Element Plus 变量（`--el-color-primary` 等）也要跟着改主色，否则组件和自定义卡片会脱节。

## 未覆盖的部分

1. **深色模式**：One UI 有完整深色规范，当前只做了浅色。若比赛现场需要投影，可以再出一版深色（改 `oneui.css` 的 `:root` 即可，结构不用动）。
2. **移动端**：只做了登录页的窄屏适配（900px 断点），其余页面针对桌面/投屏。
3. **动效**：目前只有悬停上浮、状态点呼吸、图表 340ms 过渡。One UI 的转场动效（共享元素、弹性曲线）未做。
